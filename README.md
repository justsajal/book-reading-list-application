# Book Reading List Application

A browser-based app to keep track of books you want to read, are currently reading, or have finished.

## Run
Open `index.html` in a browser. No build step is required.

## Features
- Add a book title and author
- Choose a reading status
- Search books
- Filter by status
- Delete entries
- Save entries in the browser using localStorage

## Important
The list is stored in the current browser on the current device. It is not a cloud database and will not automatically sync to another device.
